# Verity roadmap

## v1.1 (shipping 2026-11-09)

Decisions and their reasons are in [DECISIONS_v1.1.md](DECISIONS_v1.1.md).

- **Rust core** (`crates/verity-core`): field schema, the written controls, verdicts. No network, no `unsafe`. The Python controls stay in place for now, and a parity harness proves both produce identical findings.
- **Native binary** (`crates/verity`): `verity audit` (one document or a whole file), `verity explain`, `verity verify`, `verity mcp` (stdio, or `--http` for private self-hosting). Single file, no Python, no API hop.
- **Token-lean MCP**: `audit`, `audit_batch`, `explain`, `trace`. Compact by default, `verbose` on request.
- **Forensic controls**: Benford first-digit (batch), near-duplicate, sequential and reused invoice numbers, currency-aware round amounts.
- **Provenance**: every finding carries its source file, row, sha256 and related documents. It is browsable in an offline HTML report and queryable over MCP `trace`.
- **History**: Postgres (`DATABASE_URL`) for cross-run history. Batch runs use in-batch history. With no database, cross-run controls report `not_evaluated`. They never pass silently.
- **Real-data benchmark**: UK government spend over £25k, USAspending and CORD. Fetched once into a hashed snapshot and audited offline. Every published number is regenerated by one command.
- **Security**: strict input schemas and size caps. Untrusted text is returned as quoted data. No tool writes files, runs commands or calls the network. The HTTP mode requires a token and checks Origin. HTML output is escaped and served under a CSP.
- **Identity**: the bracket-V dot-matrix mark. Green = pass, amber = review, watermelon = blocked, each with its own shape.
- **Installs**: GitHub Release binaries, `cargo install`, `uvx`, and config blocks for Claude Desktop, Claude Code, Cursor, Gemini CLI, Antigravity, Codex, Windsurf and VS Code. ChatGPT is supported through a self-hosted OpenAPI Action.

## After v1.1

- PyO3 bindings so Python calls the Rust core, then delete `src/verity/policy/rules.py` to leave a single source of truth.
- Drill-down in the FastAPI review screen (finding → source → related documents).
- Port further hot paths (API, batch) to Rust where profiling justifies it.
- TLS for remote Postgres connections from the binary.
- Optional hosted HTTP instance (private, token-gated).
- crates.io publish. Official MCP registry entry `com.uncoalesced/verity` (needs the DNS TXT record). Glama, Smithery, and a PR to awesome-mcp-servers.
- More datasets: other UK departments, NYC Checkbook, EU TED.
- Weekend and holiday dating control, and purchase-order matching (needs a PO master).
- Refresh the uncoalesced.com project preview with the new assets.
- Python optimisation pass following `python_refactor.md` (deferred from v1.1; the Rust core took priority).
